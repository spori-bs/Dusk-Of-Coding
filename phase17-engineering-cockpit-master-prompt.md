# ⚡ Phase 103: The "Engineering Cockpit" UI for Dusk of Coding

Act as a Lead Motion Designer for a high-end IDE. The goal is to create a "Technical WOW" factor that emphasizes human agency over AI automation.

## 🎨 Visual Identity: "The Obsidian Foundry"
* **Aesthetic:** Dark, high-density, "Mission Control" UI. 
* **Primary Color:** #0D0D0E (Obsidian).
* **Accent:** #F59E0B (Industrial Amber - representing the "Dusk" and "Alertness").
* **Typography:** 'Geist Mono' (Free/Vercel) for a sharp, mathematical feel.

## 🚀 The "WOW" Components:

### 1. The Interactive "Logic PCB" Background (Free/SVG-based)
* **Visual:** A subtle, static grid of circuitry lines. 
* **Interaction:** On mouse-hover, the "traces" (lines) near the cursor light up in Amber. It feels like the user is "powering" the interface just by being there.

### 2. The "De-Blur" Hero Section
* **The Hook:** The main headline "Master the Craft. Wield the Tool." starts completely pixelated or "glitched." 
* **The Reveal:** As the user hovers over the text, the pixels resolve into razor-sharp, high-contrast typography. This symbolizes "Clarity through Mastery."

### 3. The "Socratic Wave" Terminal
* **Visual:** Instead of a chat bubble, the AI Mentor is a 1D line at the bottom of the code editor. 
* **Interaction:** When the user writes code, the line vibrates based on "Code Safety." If the user asks the AI for a "solution," the line turns red and jagged (Warning: AI is being used as a Brain). If the user asks for "guidance," it glows a steady Amber.

### 4. The "Bento-Switch" (Functional Layout)
* **Action:** No static cards. Use "Collapsible Modules." The UI should feel like a foldable multi-tool. Clicking a feature "deploys" it with a mechanical, snapping animation.

## 🛠️ Execution Rules (Free & Performant):
* **Animations:** Use only `framer-motion` (Free MIT License) and standard CSS transitions. 
* **No Heavy Assets:** No videos, no large 3D models. Everything must be generated via code (SVGs, CSS Gradients, Canvas) to keep the "Vibecoding" spirit.
* **Anti-AI Look:** Avoid "Glows." Use "Sharpness." Avoid "Soft Edges." Use "Hard 90-degree corners."
