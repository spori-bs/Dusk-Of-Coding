# 2026 Visionary UI/UX Design Prompt for "Dusk of Coding"

Act as a world-class, award-winning UI/UX designer and frontend developer. Create a cinematic, state-of-the-art landing page for "Dusk of Coding" - an AI-awareness and code mastery platform for developers. The site must transcend standard SaaS templates, delivering a "2026 next-gen" aesthetic that feels like an interactive journey into the future of software engineering.

## Technology Stack:

    React with TypeScript
    Tailwind CSS v4 (for advanced custom utility layers)
    Framer Motion (for scroll-driven cinematic sequencing & micro-interactions)
    WebGL / Three.js (React Three Fiber) - for subtle, interactive background elements
    Lucide React icons
    shadcn/ui (heavily customized headless components)

## Design Requirements - "2026 Aesthetic & Anti-Template Paradigm":

    Color Scheme & Theme (Ethereal Cyber-Noir):
        Background: Deep abyssal void (slate-950/black) transitioning into twilight hues (deep ultraviolet #2A0845, electric fuchsia #FF007F).
        Interactive Background: An underlying WebGL abstract particle network (representing neural nets and code execution) that reacts to the user's cursor (repulsion/attraction) and parallax scrolls.
        Glassmorphism & Claymorphism: Evolved glass effects with dynamic noise/grain overlays and frosted depth.

    Core UX/UI Behaviors (The Wow Factor):
        Magnetic Micro-interactions: Buttons and links gently pull towards the cursor on hover.
        Dynamic Cursor: A custom blend-mode cursor that acts as a "flashlight," illuminating hidden code snippets subtly etched into the dark background.
        Smooth Cinematic Scrolling: Implement smooth-scrolling mechanics (e.g., Lenis) so parallax and scroll-triggers feel weighty and premium.
        Scroll-Sequencing: Forego standard "scroll down, see next block" behavior. Use pinned scroll sections where the background morphs to tell the story while foreground elements assemble themselves via split-text reveals and 3D tilts.

## Layout Sections & Cinematic Journey:

    Navigation Bar (The HUD):
        Floating, pill-shaped glassmorphism nav-dock dynamically hiding/showing on scroll.
        Logo: Breathes with a subtle CSS shadow glow.
        "Sign In" button features a liquid gradient hover state.

    Hero Section (The Twilight Veil):
        Visuals: Immersive full-viewport height. The background features the WebGL interactive nodes. In the center, a translucent 3D glass monolith or floating code editor window that subtly tilts based on mouse movement (mousemove parallax).
        Typography: "Master the Craft. Wield the Tool." presented with a cinematic fade-in-up, combined with a literal "dusk" to "dawn" lighting sweep effect matching the cursor.
        Two CTA buttons: "Start Learning" (sweeping laser border animation) and "Watch Demo" (magnetic outline).

    Features (The Asymmetrical Bento Grid):
        Instead of a generic 3-column, 6-card grid, create an interactive, interlocking "Bento Box" layout that reveals itself asymmetrically via Framer Motion scroll-triggers as the user scrolls.
        Cards feature 3D card-tilt (reacting to mouse) and a subtle noise/grain texture overlay.
        - Sandboxed Execution: A card containing a live, typing terminal animation loop.
        - Automated Testing: A card with a circular progress ring drawing itself on scroll.
        - Socratic AI Mentor: A glowing AI "core" graphic pulsing when hovered.
        - Keycloak IAM, Bilingual Interface, Modern Dark Aesthetic: Smaller supporting bento tiles with sleek icon morphing animations.

    Philosophy Section (The Paradigm Shift):
        Scroll-triggered dramatic lighting shifts (from dark dusk to a sudden flash of vibrant dawn-light) as the user hits this section.
        Typography is massive and bold: "AI is a Tool, Not a Brain."
        Text uses a "scrubbing" animation—the opacity of words smoothly shifts from 10% to 100% as the user scrolls down (reading progress tied directly to scroll position).
        Copy:
            "AI code generation is restructuring how software is conceived, written, tested, and maintained. Developers who treat AI as their brain will hit a ceiling..."
            "At Dusk of Coding, we believe that AI is a power tool. The developers who thrive in the new dawn will be those who master the fundamentals of software engineering and learn to wield AI as their most powerful tool."

    Methodology Disclaimer (The Vault):
        Designed to look like a secure system console drawer sliding into view.
        Text has a subtle CRT glitch or terminal-scanline hover effect.
        "This repository serves as an experimental proof-of-concept. Its architecture and implementation were born from the exploratory development paradigm of 'vibecoding'..."

    Final CTA Section (The Event Horizon):
        A visual "sunrise" or "event horizon" element physically pulling layout elements towards the center on scroll.
        Heading: "Ready to Embrace the Dawn?"
        Button: "Get Started Now" sitting atop an intense, pulsating fuchsia/cyan glow that tracks the cursor's proximity.

    Footer:
        Minimalist, brutalist typography. Large brand name "DUSK" spanning the width of the screen.
        Text: "© 2026 Dusk of Coding. An experimental proof-of-concept. Master the craft. Wield the tool."

## Execution Rules:
    Never use generic template block designs. Everything must feel custom, layered, deeply interactive, and surprisingly delightful.
    Rely heavily on Framer Motion for fluid layout transitions, orchestrated enter/exit animations, and scroll-linked progressions.
